# Models
The following models are available in the application:
### User
- Represents a user in the application, with attributes such as `id`, `name`, `email`, and `password`.
### Product
- Represents a product in the application, with attributes such as `id`, `name`, `description`, and `price`.
### Order
- Represents an order in the application, with attributes such as `id`, `user_id`, `product_id`, and `status`.
