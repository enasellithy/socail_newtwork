# Directory Structure
The codebase is divided into the following main directories:
- `app`: This directory contains the application's core logic, including controllers, models, and service providers.
- `config`: This directory contains configuration files for the application.
- `database`: This directory contains database migration files and schema definitions.
- `public`: This directory contains publicly accessible files, such as images and JavaScript files.
- `resources`: This directory contains resource files, such as views and translations.
- `routes`: This directory contains route definitions for the application.
- `tests`: This directory contains test files for the application.
